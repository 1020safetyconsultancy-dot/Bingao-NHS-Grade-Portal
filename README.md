# Bingao NHS Grade Portal

Secure web-based grade portal for Bingao National High School.

## Features

- Student, Adviser, and Administrator login
- Supabase online database
- Student masterlist and secure User ID generation
- Bulk Excel student import
- Bulk Excel grade import
- Adviser all-subject grade entry
- Student grade viewing
- Role-based access

## Website

This repository is prepared for GitHub Pages deployment from the `main` branch.
